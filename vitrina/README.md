# Сайт-портфолио (Витрина)

Твой личный сайт: первый экран, примеры работ, что получает бизнес, варианты записи, этапы работы, вопросы и контакты. Цен на сайте нет.

Новую работу добавить просто: допиши объект в массив `works` в `src/data/site.js` и укажи `cover` (скриншот).

## Запуск

1. Распакуй архив и в VS Code открой **File → Open Folder** папку `vitrina` (ту, где лежит `package.json`).
2. В терминале (`Ctrl + ~`):

```bash
npm install
npm run dev
```

3. Открой http://localhost:4321/mescoutt/

## Что поменять в первую очередь — `src/data/site.js`

- `site.name` — твоё имя или название студии (сейчас «Витрина»).
- `telegram`, `telegramLabel`, `whatsapp`, `phone` — твои контакты.
- `works[].url` — ссылки на опубликованные сайты. Пока ссылки нет, у работы написано «скоро онлайн»; как вставишь — появится кнопка «Смотреть сайт», а превью станет кликабельным.
- `works[].cover` — по желанию свой скриншот: положи файл в `public/images/` и укажи `'/images/grafit.jpg'`. Без скриншота показывается мини-превью, нарисованное кодом в стиле каждого сайта.
- `faq`, `process`, `features` — тексты блоков, правь под себя.

Цвета — в начале `src/styles/global.css` (`--accent` — синий акцент).

## Публикация

Витрина и 4 работы публикуются одним сайтом на GitHub Pages:

- `https://mescout59.github.io/mescoutt/` — витрина (эту ссылку отправляешь клиентам)
- `https://mescout59.github.io/mescoutt/grafit/`, `/pudra/`, `/mtvare/`, `/penka/` — работы

Ссылки на работы уже стоят в `works[].url`. Работы открываются в той же вкладке,
а обратно ведёт кнопка «← Портфолио» в углу каждого демо-сайта.

Собрать всё локально: в папке «Портфолио» выполни `node scripts/build-all.mjs`, результат в `_site/`.
На GitHub то же самое автоматически делает `.github/workflows/deploy.yml` при каждом `git push`.
