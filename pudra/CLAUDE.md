# PUDRA: сайт салона красоты (демо)

Часть портфолио фриланс-разработчика сайтов для малого бизнеса. Соседние проекты в папке `Портфолио`:
grafit (барбершоп), pudra (салон красоты), mtvare (грузинский ресторан), penka (кофейня), vitrina (сайт-портфолио с этими 4 работами).

## Стек
Astro 5 · GSAP + ScrollTrigger (анимации при скролле) · Lenis (плавный скролл) · обычный CSS, без Tailwind.
Сайт статический, одна страница. Команды: `npm install`, `npm run dev` (localhost:4321/mescoutt/pudra/), `npm run build` (в `dist/`).

## Структура
| Что | Где |
|---|---|
| Все тексты, цены, меню, контакты, id фото Unsplash | `src/data/site.js` |
| Блоки страницы | `src/components/*.astro` |
| Порядок блоков | `src/pages/index.astro` |
| Общий шаблон (head, шрифты, подключение скрипта) | `src/layouts/Layout.astro` |

| Анимации и интерактив | `src/scripts/main.js` |
| Описание для заказчика / запуск | `README.md` |

## Особенности
- Стиль: светлый, пудровый.
- Онлайн-запись: `site.bookingUrl` в `site.js`. Сейчас там заглушка `https://n000000.yclients.com/`, поэтому кнопки записи открывают демо-окно (`BookingModal.astro`). Реальная ссылка клиента вида `https://n123456.yclients.com/`.
- Иконки: `Icon.astro`.

## Публикация и кнопка «← Портфолио»
- Все 5 проектов публикуются одним сайтом на GitHub Pages: витрина в корне `https://mescout59.github.io/mescoutt/`, этот проект в `/mescoutt/pudra/`.
- Поэтому в `astro.config.mjs` стоит `base: '/mescoutt/pudra/'`. Локально сайт открывается на `localhost:4321/mescoutt/pudra/`.
- Пути к своим файлам из `public/` писать с учётом base: `import.meta.env.BASE_URL` (так сделано для favicon и в `img()` в `site.js`). Голый `/файл` сломается.
- `BackLink.astro` — кнопка «← Портфолио» внизу слева, ведёт на `site.portfolioUrl` (папка выше, т.е. витрина). Пусто — кнопки нет.
- Общая сборка: `node scripts/build-all.mjs` в папке «Портфолио» → `_site/`. На GitHub это делает `.github/workflows/deploy.yml` при push в main.

## Правила
- Всё на русском: тексты сайта, комментарии, ответы.
- Не обновлять Astro до новой мажорной версии (остаёмся на 5.x). `npm audit fix --force` не запускать: он ставит Astro 7.
- Не менять дизайн без согласия владельца, делать только то, о чём просят.
- Контент менять в `site.js`, а не хардкодить в компонентах.
- После изменений: `npm run build` без ошибок и проверка вида на телефоне (ширина ~390px, без горизонтальной прокрутки).
