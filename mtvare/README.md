# МТВАРЕ: сайт грузинского ресторана (демо для портфолио)

Astro + GSAP (анимации при скролле) + Lenis (плавный скролл). Без лишних зависимостей.

## Запуск (один раз)

1. Установи **Node.js LTS**: https://nodejs.org (кнопка LTS, всё по умолчанию).
   Проверка в терминале: `node -v` должна показать версию 20 или выше.
2. Распакуй архив, например в `C:\Projects\mtvare` (Laragon для этого не нужен. Важно: открывай в VS Code именно папку `mtvare`, где лежит `package.json`).
3. В VS Code: **File → Open Folder** и выбери папку `mtvare`.
   VS Code предложит расширение **Astro**. Установи его, оно добавит подсветку кода.
4. Открой терминал: **Terminal → New Terminal** (или `Ctrl + ~`) и выполни:

```bash
npm install
npm run dev
```

5. Открой в браузере адрес из терминала, обычно http://localhost:4321/mtvare/ (с подпапкой, см. «Публикация» ниже).
   Сохраняешь файл, и страница обновляется сама.

Остановить сервер: `Ctrl + C` в терминале.

## Где что менять

| Что | Файл |
|---|---|
| Тексты, цены, мастера, отзывы, фото, телефон, адрес | `src/data/site.js` |
| Цвета, шрифты, отступы | `src/styles/global.css` (блок `:root` в начале) |
| Анимации | `src/scripts/main.js` |
| Разметка отдельных блоков | `src/components/*.astro` |
| Порядок блоков на странице | `src/pages/index.astro` |

**Фото.** Сейчас они подгружаются с Unsplash (бесплатно для коммерческого использования).
Чтобы поставить свои, положи файлы в `public/images/` и укажи в `site.js` путь вида `'/images/hero.jpg'`.
Тёмные затемнения поверх фото задаются в CSS (`::after` у `.hero__bg`, `.wine__bg`, `.contacts__bg`).

**Онлайн-запись YCLIENTS.** В `site.js` поле `bookingUrl` сейчас содержит заглушку,
поэтому кнопки «Записаться» открывают демо-окно. Вставь реальную ссылку клиента
(вида `https://n123456.yclients.com/`), и кнопки поведут в его онлайн-запись.

## Публикация в интернет (бесплатно)

Сайт публикуется не отдельно, а вместе со всем портфолио: один сайт на GitHub Pages,
этот проект лежит в подпапке `/mtvare/` (адрес `https://mescoutt.github.io/mtvare/`).
Как это устроено и как опубликовать, описано в `CLAUDE.md` этого проекта
и в `scripts/build-all.mjs` в папке «Портфолио».

**Важно при запуске:** из-за подпапки локальный адрес тоже с ней:
http://localhost:4321/mtvare/ (просто localhost:4321 покажет страницу 404).

**Кнопка «← Портфолио»** в левом нижнем углу ведёт на витрину.
Адрес задаётся в `site.js` (`portfolioUrl`). Для настоящего сайта клиента поставь там `''`.

**Если делаешь из этого проекта сайт для реального клиента** на его домене:
убери `base` из `astro.config.mjs`, впиши его домен в `site` и поставь `portfolioUrl: ''`.

## Особенности этого сайта

- Меню и винная карта: раздел меню с вкладками — в `site.js` массив `menu`, вина — `wines`.
- Горный силуэт между блоками — компонент `Mountains.astro`, слои двигаются с разной скоростью при скролле.
- Часы работы по дням выводятся из `site.hours` — поменял там, и они обновятся и на первом экране.
- Кнопки «Забронировать стол» открывают демо-окно. Для реального ресторана вставь ссылку сервиса брони в `bookingUrl`.
- В `astro.config.mjs` уже включено `server: { host: true }` — сайт открывается и по localhost, и с телефона в той же Wi-Fi.
